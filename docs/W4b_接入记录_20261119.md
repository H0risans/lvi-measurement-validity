## 3. 接入链路

### 3.1 图像与点云

```
/alphasense/cam0/image_raw (40 Hz)
  → camera_fault_injector (hilti22_select10.yaml, passthrough + select_stride=4)
  → /fault_injector/image_raw (10 Hz)
  → hilti_r3live_adapter
  → /r3live_hilti_adapter/image_out (720×540, 去畸变针孔)

/hesai/pandar (Hesai XT32 PointCloud2)
  → hilti_lvisam_adapter/point_cloud_converter.py
  → /lvisam/points (PointXYZIRT: x,y,z,intensity,ring,time)
```

- 注入器只做 4:1 选帧，`mode: passthrough`；不向 LVI-SAM 引入故障。
- Hilti 适配器输出的针孔图 K=`[351.314, 0, 367.852; 0, 351.491, 253.840; 0, 0, 1]`，零畸变；LVI-SAM 用 `PINHOLE`，不再做鱼眼模型。
- 转换器把 Hesai 点旋转到 IMU 轴：`xyz @ R_IL.T`，`R_IL=[[0,-1,0],[-1,0,0],[0,0,-1]]`；**不平移**，平移由 LVI-SAM 的 `extrinsicTrans=T_IL=[-0.001,-0.00855,0.055]` 承担，避免双重平移。
- 输出字段固定为 `x,y,z,intensity,ring,time`，`point_step=24`，偏移 0/4/8/12/16/20；`ring` 保留 0–31，`time` 为相对扫描起始的秒；字段缺失、`ring≥32`、非有限坐标或时间跨度超 `max_rel_s=0.2` 时拒发整帧，不伪造扫描。

### 3.2 LVI-SAM 配置

- 点云：`pointCloudTopic: /lvisam/points`、`imuTopic: /alphasense/imu`、`N_SCAN: 32`、`Horizon_SCAN: 1800`、`timeField: time`、`loopClosureEnableFlag: false`、`useImuHeadingInitialization: false`。
- 相机：`model_type: PINHOLE`、`image_topic: /r3live_hilti_adapter/image_out`、`fisheye: 0`、`loop_closure: 0`、`show_track: 0`；`extrinsicRotation=R_IC`、`extrinsicTranslation=t_IC`。
- 外参：`R_IC=[[0.00670802,0.00242564,0.999975],[0.999926,0.0100912,-0.00673218],[-0.0101073,0.999946,-0.00235777]]`，`t_IC=[0.051263551,0.0453901,-0.013214874]`（相机→IMU，来自 Hilti 适配器）。
- 不启动 `lvi_sam_visual_loop`，因此不需要词袋文件；LVI-SAM 的五个核心模块 + IMU 预积分共六个节点。
- 监督层：image `/r3live_hilti_adapter/image_out`、lidar `/lvisam/points`、odom `/lvi_sam/lidar/mapping/odometry`，`hold_output=true`；`lidar_p05=55008`、`lidar_p50=58931`（exp18 R3LIVE 点云标定值，仅作本轮占位，不是 LVI-SAM 前端口径的最终标定）。

## 5. 尚未验证 / 已知限制

1. **没有精度评测**：W4b clean 行已有 LIO 输出，但没有真值对齐、没有 APE/RPE；VINS 侧反复 reboot，视觉-惯性融合稳定性未验证，不能与 FAST-LIVO2/R3LIVE 比较。
2. **外参方向未用轨迹验证**：`R_IL`/`T_IL`、`R_IC`/`t_IC` 来自 Hilti 适配器与手工推导；目前只有字段/量程检查，没有点云-图像对齐或轨迹一致性证据。
3. **时间字段**：转换器输出的 `time` 是相对扫描起始秒；LVI-SAM 的 deskew 是否与 Hesai 时间基完全一致，尚未用运动场景核验。
4. **IMU 噪声参数**：`params_lidar_hilti.yaml` 仍沿用 LIO-SAM 模板的 IMU 噪声/重力模长占位，未按 Hilti IMU 标定；任何精度/一致性结论都不能引用。
5. **supervisor 阈值**：`lidar_p05/p50=55008/58931` 是 R3LIVE 原始点云条数口径；LVI-SAM 若改用有效约束数，必须重新标定。
6. **未触发弃权**：clean exp18 全 OK，`hold_output` 的行为未被实际执行；W4a 的 clean 行也未触发。
7. **未做 loop closure**：为降低变量，`loopClosureEnableFlag=false` 且不启 visual_loop；因此本适配不代表 LVI-SAM 的完整建图能力。
