# W4a 接入记录（R3LIVE clean exp18，2026-11-19）

## 目的

在不改 R3LIVE 源码的前提下，用外部 supervisor 消费 R3LIVE 实际使用的图像、点云与 `/aft_mapped_to_init`，发布 `/safety/state` 与 `/safety/odom`，作为三 LIVO 复用路线的第二个算法接入证据。

## 链路

```text
exp18 bag
  → /alphasense/cam0/image_raw
  → camera_fault_injector（hilti22_select10.yaml，passthrough + 4:1 选帧，10 Hz）
  → /fault_injector/image_raw
  → hilti_r3live_adapter
  → /r3live_hilti_adapter/image_out + /r3live_hilti_adapter/cloud_out
  → r3live_mapping + safety_supervisor
```

关键点：adapter 的契约是“只接收已选/已注入图像”；直接把 40 Hz 原始图送 adapter 会让 R3LIVE 的 VIO 阻塞、LIO 停更。必须保留 injector 的 10 Hz 选帧。
