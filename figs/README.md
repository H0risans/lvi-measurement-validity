# Paper figures

Three figures are generated by `make_figs.py`. Labels are English and use Arial. Outputs are SVG (vector) and PDF (Edge headless print, 190 mm wide).

- `fig1_pipeline.svg`: event-level injection and processing-exposure verification (schematic).
- `fig2_support.svg`: in-window valid inlier count for content replay; data from `data/content_replay/<tag>/safety_risk.csv`.
- `fig3_output_hold.svg`: published-pose envelope under online output hold (log scale); data from `data/hold/a_results.csv`.

Regenerate the SVGs from the repository root:

```bash
PYTHONIOENCODING=utf-8 python figs/make_figs.py
```

The script uses only the Python standard library. For Fig. 2, the baseline band is the interquartile range of the same run at `t<29 s` or `t>33 s`; the shaded interval is `[30,32)` s. In Fig. 3, group B did not resume (its envelope stays at about 5.3 m); this must not be interpreted as an effective output hold.
